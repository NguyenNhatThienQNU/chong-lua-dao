TRIỂN KHAI "TRUNG TÂM CHỐNG LỪA ĐẢO" LÊN VERCEL (khoảng 10 phút)

Thư mục này gồm:
  index.html      bản Học sinh (HS mở trang chủ)
  gv.html         bản Giáo viên (màn chiếu + Bảng theo dõi)
  api/ketqua.js   API lưu kết quả của học sinh

CÁCH 1: QUA GITHUB (không cần cài gì)
1. Vào github.com > New repository > đặt tên (vd: chong-lua-dao) > Create.
2. Bấm "uploading an existing file", kéo thả TOÀN BỘ nội dung thư mục này
   (index.html, gv.html, thư mục api) > Commit changes.
3. Vào vercel.com > đăng nhập bằng GitHub > Add New... > Project > Import repo vừa tạo > Deploy.
4. Trong project vừa tạo: tab Storage > Create Database > chọn Upstash (Redis) > gói Free >
   Connect to project (giữ tên biến mặc định).
5. Settings > Environment Variables > thêm MAT_KHAU = mật khẩu của bạn > Save.
6. Deployments > bấm "..." ở bản mới nhất > Redeploy (để nhận Redis và mật khẩu).

CÁCH 2: DÒNG LỆNH (nếu máy có Node.js)
  Mở cmd trong thư mục này, chạy:  npx vercel --prod
  Sau đó làm bước 4, 5, 6 như trên.
